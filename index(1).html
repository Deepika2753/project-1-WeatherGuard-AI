WeatherGuard AI

A smart weather intelligence and risk advisory dashboard that combines live weather data with a rule-based risk engine to classify conditions as Low, Moderate, or High risk and provide practical safety guidance.

Open Live Demo → View Source Code

Live Weather

Search cities and retrieve current conditions along with forecast information using a weather API.

Risk Assessment

Uses weather factors such as rainfall, wind, and temperature to generate Low, Moderate, or High risk levels.

Safety Advisory

Provides clear recommendations so users can quickly understand possible weather-related risks.

Core Features

City Search Search weather information for different cities through a clean web interface.
Forecast Display Shows current weather and forecast information in an easy-to-read dashboard.
Automated Risk Level Generates a weather risk category based on predefined conditions and thresholds.
Persistent User Data Supports stored search history and favorites using SQLite in the deployed Flask application.

Tech Stack

Python Flask HTML CSS JavaScript SQLite Weather API Render

Why I built it

Weather information is useful, but raw numbers alone may not immediately tell users how risky the conditions are. WeatherGuard AI turns weather data into a simple risk level and safety advisory, making the information easier to understand and act upon.
